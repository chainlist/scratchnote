# Mentions

Mention people, projects or anything else with an at sign:

```markdown
Call @marie about the offsite, and ask @build-team for the numbers.
```

A mention shows as a chip. A click on one opens a page listing every note and page of the space that mentions that name, newest first.

## Every mention

**Show every mention** in the command center lists every name used, most mentioned first. A click on a name opens its notes.

## How names are read

- A name is letters and digits of any script, with `_` and `-` inside it: `@marie`, `@Zoë`, `@build-team`.
- Case does not count: `@Marie` and `@marie` are the same person.
- An email address is left alone: `marie@example.com` is not a mention.
